ツアー報告・お客様の声

お客様の声

40代 / 女性

30代後半で初めてのゲレンデデビューをしました。家族の中では次男と私がスキーにどっぷりとハマり、初級者コースをヨチヨチと滑っているうちに、次男は若さもありメキメキと上達。私が独り立ちを目指してる中、ナイスミドルツアーを見つけました。
ワンシーズン、逡巡して満を持して菅平のレッスン付に申し込んでみたら！すっかり虜になりました。来シーズンが待ち遠しいです。

50代 / 女性

今の私のスキー人生があるのは、ナイスミドルツアーのおかげだと思っています。初参加でも常連さんが声を掛けて頂き、仲間に入れていただいて楽しく滑走しました。そこから、どんどんスキー仲間の輪が広がり、今も一緒に滑ってもらってます。１人で参加しても、添乗員さんが声をかけてくれるので安心です。田澤君はコブの練習にも付き合ってくれました。
こんなにフレンドリーなツアーは他にないと思います。
スキーは生涯スポーツ、これからもまだまだ滑りますよ！！

40代 / 男性

ナイスミドルツアーに興味があったのですが、当時40代後半の自分は年齢的に大丈夫かなぁなんて思っていました。
勇気を出して参加したところ、添乗員さんが優しく声を掛けてくれたり、先輩方もあたたかく接していただいたお陰で楽しく滑ることができました。気がつけば4シーズン参加しています。
添乗員さんはツアー中、色々な面でアテンドしてくれるので助かります。一緒に滑ったり美味しいお昼も教えてくれます。夜の宴もたくさんの方とコミニュケーションが取れるので楽しみの一つです。来シーズンも皆さんと会えるのが楽しみです。

70代 / 男性 / 初参加

大変楽しいスキー旅行でした。寒さの中、霧氷の林、時折覗く太陽、あっという間の4日間でした。
メンバーも以前から参加されている方から、私のような初めての人間まで、旧知の仲間のように打ち解け、遅くまで楽しいおしゃべりが出来ました。
「また、会えますように」と新宿でお別れし帰途に付き、無事に帰宅することが出来ました。
またご縁がありましたら参加したいと思います。
急遽変更で、大慌てで5日間私たちの面倒を見て下さった添乗員さん始め、皆さま方に厚く御礼すると共に、今後のご活躍を祈念いたします。
